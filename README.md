# Aprende+

Protótipo navegável do conceito **Aprende+ — aprender do seu jeito**.

## Incluído
- Área da criança/adolescente
- Área da mãe/responsável
- Estudos e conquistas
- Troca de perfil
- Fluxos de dúvida, tarefa, matemática, resumo, mapa mental e quiz
- Acompanhamento e passaporte educacional (mock)
- Layout responsivo para celular
- Sem backend e sem coleta de dados reais

## Executar
Abra `index.html` no navegador.

## Publicar
Pode ser publicado como site estático no GitHub Pages, Netlify ou Vercel.

## Próxima fase
Validar com educadores, famílias e alunos antes de conectar IA, banco de dados, autenticação e dados reais.
